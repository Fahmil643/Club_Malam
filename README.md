Cara Menjalankan Website
Buka terminal di folder proyek:

Install dependency:

npm install
Jalankan server development:

npm run dev
Buka browser dan akses alamat yang muncul, biasanya:

http://localhost:5173
Pastikan Node.js sudah terpasang di komputer Anda sebelum menjalankan langkah di atas.
